Este é o primeiro post de exemplo da POC. Ele vive em `content/blog`, é versionado junto com o repositório e é processado pelo Nuxt Content durante o build.

## O que este post demonstra

- Frontmatter com título, descrição, data, capa, tags e status de rascunho.
- Conteúdo em Markdown sem chamadas para APIs externas.
- Renderização compatível com geração estática.

Com essa base, a publicação continua simples: editar arquivo, commitar no Git e deixar o GitHub Actions gerar o site.
